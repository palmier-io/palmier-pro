# Adoption Plan: HyperFrames → Compositor Pro (Design Notes & Migration Guide)

This document details the architectural integration, technical design notes, component implementations, CLI contracts, and migration paths for adopting HyperFrames motion-graphics and templating capabilities into Compositor Pro.

---

## 1. Overview & Strategy

HyperFrames provides high-velocity motion graphics, web-based kinetic typography, design specification parsing (`frame.md`), and reusable template composition. Compositor Pro is an AI-native professional video editor built on Swift 6.2, SwiftUI, AppKit, and AVFoundation.

The adoption strategy marries HyperFrames' rapid template-driven workflows with Compositor Pro's native editing substrate:
- **Single Source of Truth**: All edits, whether generated by HyperFrames catalog blocks, CLI commands, agent tools, or manual UI interactions, route through the same timeline domain mutations and shared `EditorUndo` history.
- **Dual-Engine Rendering**: Native AVFoundation pipeline for performance-critical timeline playback and ProRes/HEVC/H.264 export, combined with an isolated WebKit / headless rendering harness for HTML/CSS/JS motion blocks.
- **Strict Concurrency & Off-Main Work**: All catalog inspection, animation conversion, frame rendering, and package serialization execute off the main thread.

## 2. Capability Architecture & Backlog

### HF-01: Bidirectional `STORYBOARD.md` Bridge
- **Implementation**: [`StoryboardMarkdownCodec.swift`](../Sources/CompositorPro/Agent/Plans/StoryboardMarkdownCodec.swift)
- **Tool Integration**: `import_storyboard_markdown` and `export_storyboard_markdown` in [`ToolExecutor+Plan.swift`](../Sources/CompositorPro/Agent/Tools/ToolExecutor+Plan.swift).
- **Functionality**:
  - Parses standard `STORYBOARD.md` documents (beats, timecodes, voiceover, visual concepts, camera/motion, SFX) into native `EditPlan` structures.
  - Serializes active `EditPlan` or `StoryboardReport` back to Markdown format without data loss or cumulative timing drift.

### HF-02: `frame.md` / `design.md` Design Spec & Brand Styling Parser
- **Implementation**: [`DesignSpecParser.swift`](../Sources/CompositorPro/Agent/Plans/DesignSpecParser.swift), [`DesignSpec.swift`](../Sources/CompositorPro/Agent/Plans/DesignSpec.swift)
- **Tool Integration**: `apply_design_spec` in [`ToolExecutor+DesignSpec.swift`](../Sources/CompositorPro/Agent/Tools/ToolExecutor+DesignSpec.swift).
- **Functionality**:
  - Parses color palettes (hex values), typography rules, fonts, margins, canvas geometry, pacing curves, and aspect ratios.
  - Automatically applies styling presets to caption templates, text overlay styles, and project color grading presets.

### HF-03: `/hyperframes` Motion Playbook & Agent Skill
- **Implementation**: Registered in `FilmmakingPlaybooks.all` and [`SkillStore`](../Sources/CompositorPro/Agent/Skills/SkillStore.swift).
- **Functionality**:
  - Provides agent skills for product launch videos, kinetic typography, and motion graphics sequences.
  - Equips the agent with catalog search, parameter binding, and placement workflows for catalog motion blocks.

### HF-04: Automated Motion Graphics Track Placement
- **Implementation**: [`ToolExecutor+Hyperframes.swift`](../Sources/CompositorPro/Agent/Tools/ToolExecutor+Hyperframes.swift) (`insert_and_place_hyperframes_block`).
- **Functionality**:
  - Allows direct placement of kinetic overlays, Lottie vector animations, and motion blocks onto timeline tracks with precise keyframing and layout controls.

## 3. Phasing Breakdown & Delivery

### Phase 1: Quick Wins (Weeks 0–4)
- **Catalog Wrapper**: [`HyperframesCatalogWrapper.swift`](../Sources/CompositorPro/Hyperframes/HyperframesCatalogWrapper.swift) provides discovery, template metadata extraction, and HTML bundle generation.
- **CLI Commands**: [`CLIHandler.swift`](../Sources/CompositorPro/CLI/CLIHandler.swift) introduces `compositor-pro init`, `preview`, `render`, and `hyperframes` commands.
- **WebView Live Preview**: [`HyperframesLivePreviewView.swift`](../Sources/CompositorPro/Preview/HyperframesLivePreviewView.swift) integrates WebKit into the editor's preview container tab system (`PreviewTab.hyperframesPreview`).
- **Agent Skill**: Integrated `/hyperframes` skill for natural-language motion graphic authoring.

### Phase 2: Mid-Term (Weeks 4–12)
- **Adapter Import Tool**: [`AnimationAdapter.swift`](../Sources/CompositorPro/Tools/AdapterImport/AnimationAdapter.swift) parses GSAP and Lottie JSON and converts keyframed transformations into native timeline tracks (`positionTrack`, `scaleTrack`, `opacityTrack`, `rotationTrack`) via `import_animation_adapter`.
- **Deterministic Rendering Test Harness**: [`VisualRegressionHarness.swift`](../Sources/CompositorPro/Testing/VisualRegressionHarness.swift) enables frame-by-frame comparison against Git LFS baseline golden PNGs with pixel-diff tolerances.
- **AWS Lambda Remote Rendering**: [`AWSLambdaRenderer.swift`](../Sources/CompositorPro/Export/AWSLambdaRenderer.swift) (under the `AWSSupport` compiler trait) provides optional distributed headless rendering via S3/Lambda with graceful fallback to local export.
- **Design Spec Wizard**: [`DesignSpecWizard.swift`](../Sources/CompositorPro/UI/DesignSpecWizard.swift) and [`DesignSpecWizardView`](../Sources/CompositorPro/UI/DesignSpecWizard.swift) provide interactive visual configuration for `frame.md` attributes.

### Phase 3: Advanced (Weeks 12–24)
- **Hybrid Authoring**: [`HybridCompositionRenderer.swift`](../Sources/CompositorPro/Hyperframes/HybridCompositionRenderer.swift) and [`HybridFrameCache.swift`](../Sources/CompositorPro/Hyperframes/HybridFrameCache.swift) allow seamless compositing of HTML/JS motion blocks alongside native video clips on the same timeline.
- **Community Catalog**: [`HyperframesCommunityCatalog.swift`](../Sources/CompositorPro/Hyperframes/HyperframesCommunityCatalog.swift) enables discovery, validation, and installation of external community motion templates.
- **Cross-Platform Headless Rendering**: Headless render job export (`compositor-pro export-job`) and containerized execution (`scripts/headless/render_job.js` and `scripts/headless/Dockerfile`). See [HeadlessRendering.md](HeadlessRendering.md).
- **Performance Optimizations**: Dirty-region tracking, frame caching, and background rasterization pipelines.

## 4. CLI Usage Guide

Compositor Pro includes full headless and CLI capabilities:

```bash
# Initialize a new project with an optional template
compositor-pro init MyNewProject --template kinetic-intro

# Launch live preview in headless/local mode
compositor-pro preview path/to/project.compositorpro

# Render a project directly from the terminal
compositor-pro render path/to/project.compositorpro -o output.mp4

# Export a portable JSON render job for Linux/Windows runners
compositor-pro export-job path/to/project.compositorpro -o job.json

# Manage community motion templates
compositor-pro catalog list
compositor-pro catalog validate path/to/template-directory
compositor-pro catalog add path/to/template-directory
```

## 5. Migration Guide: From HyperFrames to Compositor Pro

### Migrating Storyboards
1. Copy existing `STORYBOARD.md` files into the project package or import via the agent:
   ```json
   { "action": "import_storyboard_markdown", "markdown": "<content>" }
   ```
2. The bridge maps storyboard beats directly to `EditPlan` sections, preserving voiceover text, timing bounds, and visual prompts.

### Migrating Brand & Design Specs
1. Supply `frame.md` or `design.md` via `apply_design_spec`:
   - Hex colors are parsed into `PaletteColor` values and map to captions and text layers.
   - Typography rules set project font hierarchies and title sizing.
   - Aspect ratio constraints reconfigure canvas dimensions (16:9, 9:16, 1:1, etc.).
2. Use the in-app Design Spec Wizard (`open_design_spec_wizard`) to tweak parameters visually.

### Migrating HTML/CSS/GSAP Motion Templates
1. Convert GSAP / Lottie keyframes directly to native timeline tracks using `import_animation_adapter` for zero-overhead hardware playback.
2. For complex, non-convertible web layouts, use hybrid compositions (`create_hybrid_composition`) to render web templates dynamically onto timeline overlay tracks.
